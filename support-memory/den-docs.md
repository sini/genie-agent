den is `github:denful/den`. Its documentation site is https://den.denful.dev, built from the
repository's `docs/` directory. Good starting pages: "From Zero to Den"
(`/guides/from-zero-to-den/`), "From Flake to Den" (`/guides/from-flake-to-den/`) and "Core
Principles" (`/explanation/core-principles/`). Runnable examples live under `templates/`, for
example `nix run github:denful/den?dir=templates/microvm#runnable-microvm`.

Source: `github:denful/den`, `README.md` ("Documentation").
