**Rule:** A session that never loads the orchestrator's boot, instructions and tracker is reading the
artefact in front of it, not checking standing law. Before answering a design question, recall from
the standing-law memory bank, label each fact as measured or synthesized, and relay anything that
needs a ruling or the tracker graph to the session that holds them.

**Why:** Asked to list its gaps against a fully booted session, the support assistant found that the
orchestrator repo's agent instructions name the law bank as a source for every agent, and it had not
been using it. One of its design notes to a contributor had come from a single gist.

**How to apply:**

- Design questions only, not support or operations questions.
- Treat world/experience facts as measured and observation facts as synthesized, to be verified at
  HEAD (\[[memory-bank-derived-observations]\]). Say which kind each one is in the answer.
- Never rule; relay to the session that owns rulings (\[[cross-session-messaging]\]).
